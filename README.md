# 静盒 (QuietBox)

一个面向小红书的 LSPosed 模块：去掉广告、收敛弹窗、收紧隐私，让 App 安静下来。

基于 [libxposed](https://github.com/libxposed) Modern API 102，纯 Java Hook 实现。

> ⚠️ 本项目与小红书官方无任何关联，仅供学习、研究和个人设备使用。
> 使用前请阅读文末的[免责声明](#免责声明)。

---

## 功能

24 项功能，**21 项可用**，每项独立开关、默认关闭。改动需重启小红书生效（AB 面板的单项实验约 3 秒生效）。

### 广告

| 功能 | 说明 |
|---|---|
| 开屏广告跳过 | 覆盖内嵌 Fragment、独立全屏 Activity、冷启动占位三条路径 |
| 信息流广告过滤 | 开屏关联广告与服务端下发的普通广告都过滤 |
| 评论广告过滤 | 隐藏评论区广告组件 |
| 广告外跳拦截 | 广告落地页不拉起淘宝、京东等外部 App |
| 搜索广告过滤 | 搜索结果里不显示广告 |
| 详情页广告条屏蔽 | 隐藏笔记详情页底部的二跳广告条 |
| 评论区带货插入屏蔽 | 评论区顶部不再插入商品卡 |
| 直播卡过滤 | 信息流里不显示直播卡片 |
| 带货卡过滤 | 信息流里不显示商品笔记卡 |
| 投票卡过滤 | 信息流里不显示投票卡片 |

### 打扰与引导

| 功能 | 说明 |
|---|---|
| 评分引导弹窗屏蔽 | 不弹「满意吗 / 去评分」和系统评分 |
| 通知引导弹窗屏蔽 | 不弹「开启通知」引导；手动开通知不受影响 |
| 满意度调研条屏蔽 | 详情页不再弹出「对内容满意吗」 |

### 内容与浏览

| 功能 | 说明 |
|---|---|
| 已删除笔记查看 | 实验性：笔记被删除后，仍用手机上已缓存的内容展示；没有缓存时不会伪造内容。该恢复路径仅理论验证，未在真实被删笔记场景实测 |

### 界面与隐私

| 功能 | 说明 |
|---|---|
| 更新弹窗屏蔽 | 不再弹出版本更新提示 |
| 截图检测关闭 | 不注册截图监听；手动分享不受影响 |
| 通讯录同步关闭 | 不上传通讯录，不再有通讯录推荐好友 |

### 分享与播放

| 功能 | 说明 |
|---|---|
| 复制链接净化 | 去掉链接里的追踪参数（`xsec_token` 默认保留，可单独勾选删除） |
| 水印策略 | 保存图片时不带水印 |
| 自动播放 | 关闭详情页/视频 tab 的自动播放（画质偏好本版本不提供） |

### 测试（实验开关）

| 功能 | 说明 |
|---|---|
| AB 测试面板 | 强开小红书灰度实验。底栏「测试」页内置 21 个高价值、纯客户端的实验开关（详情页渲染、播放体验、评论键盘等），并展示模块探测到的其他实验 key；未收录项只读，不建议修改。支持把全量 key + 当前探测值导出为 CSV |

> 强开的是灰度实验组，不是隐藏福利。部分实验依赖服务端配套数据，可能出现页面空白或崩溃。
> 请一次只开一项、逐项验证；广告、埋点、直播、服务端调参类实验不提供开关。

### 本版本不提供

| 功能 | 原因 |
|---|---|
| 默认静音 | 小红书自带自动静音，多做一层反而会覆盖用户设置 |
| 摇一摇跳转禁用 | 广告摇一摇的检测在原生引擎侧，Java 层没有可靠的拦截点 |
| 埋点抑制 | 本版本没有安全的挂载点，强行拦截会影响应用生命周期 |

## 环境要求

- Android 10 及以上
- 已安装 **LSPosed**（Zygisk 版，配合 Magisk / KernelSU）
- **小红书 9.50.0（versionCode 9500803）**

其他版本可能只有部分功能生效，甚至完全不生效——模块的 Hook 点依赖具体版本。

## 安装

1. 从 [Releases](../../releases) 下载 `quietbox-x.y.z.apk` 并安装。
2. 打开 **LSPosed 管理器**，在模块列表里启用「静盒」。
3. 进入模块的作用域设置，勾选 **小红书**（`com.xingin.xhs`）。
4. 打开「静盒」，确认顶部显示 **已激活**，且副标题包含 **已注入小红书**。
5. 按需打开开关。

## 常见问题

**开关是灰色的？**
模块 App 还没绑定到 LSPosed 服务。等一两秒会自动刷新；一直灰着就检查 LSPosed 里模块是否启用、作用域是否勾选。

**某项功能没效果？**
先看 logcat（tag `QuietBox`）：
- 注册成功会打印 `P1-13 registered fl0.f0#o`
- 命中会打印 `P1-13 hit search ads removed=3`

没有注册日志，说明这个版本的挂载点没找到，大概率是小红书升级后内部结构变了。请看「兼容性」。

**升级小红书后失效了？**
正常现象。模块依赖具体版本的内部结构，升级后需要重新适配。如果顶部出现
「当前小红书版本可能不兼容」的红色提示，并显示 N/M 个功能有挂载点失效，
就是这个原因。可以先回退到 9.50.0，或关注 Releases 里的版本说明。

**会不会导致封号？**
模块不修改账号数据、不拦截网络请求、不上传任何信息。但它确实会 Hook 目标应用进程，理论上存在被检测的可能。是否使用、是否用于主账号，请自行评估并承担风险。

**和同类模块冲突吗？**
同时使用多个 Hook 同一应用的模块可能互相覆盖。建议只保留一个。

**需要给静盒加自启动白名单吗？**
不需要。功能开关通过 LSPosed 的 remote preferences 传递。AB 测试面板的探测数据
由小红书进程单向写入模块 App 的本地 ContentProvider，只在本机展示，不联网、不上传。

## 隐私

- **不申请网络权限**，App 本身无法联网。
- 无统计、无遥测、无崩溃上报、无后台服务。
- 不读取、不上传你的任何数据。
- 所有逻辑都在本机目标进程内完成。
- AB 测试面板的探测结果只写入模块 App 的本地存储（`ab_report`），仅用于界面展示。
- 模块只在 LSPosed 中勾选的应用里生效。

## 从源码构建

```bash
# 依赖缓存放 D 盘（按需修改）
set GRADLE_USER_HOME=D:\gradle-home

gradlew assembleDebug      # 调试包
gradlew assembleRelease    # 正式包，产物名 quietbox-<版本>.apk
```

release 优先读仓库根目录的 `keystore.properties` 签名（该文件不入库）。
没有时借用 debug 证书，开箱即可构建安装。

工具链：Gradle 8.13（wrapper） · AGP 8.12.2 · compileSdk 37 · minSdk 29 · Java 17。
首次构建需要自己提供 `local.properties`（`sdk.dir=<SDK 路径>`）。
