# 静盒 0.4.0

新增「测试」底栏：AB 实验开关面板。

## 新增

- 底栏改为「功能 / 测试」两栏。
- 「测试」页内置 19 个高价值、纯客户端的 AB 实验开关：
  - **详情页与信息流（8 项）**：正文排版优化、详情页滚动优化、图片详情布局缓存、正文预解析、互动栏首帧优化、异步预计算文本、详情页布局预加载、个人页布局预取。
  - **播放体验（7 项）**：进度条自动隐藏、播放位置记忆、切后台继续播放、边缘手势排除、播放震动反馈、视频轻量 UI、字幕新样式。
  - **其他推荐（4 项）**：评论键盘优化、首页视频预加载、搜索页深色修复、首页红点优化。
- 最底部「其他（探测到，未收录）」：展示模块在宿主进程读到的其他 AB key 与当前值，只读；广告/埋点/直播/服务端调参类标记「不推荐修改」。50 条一批，滚到底自动加载，底部保留「加载更多」兜底。
- 探测数据由小红书进程单向写入模块 App 的本地 ContentProvider，只在本机展示，不联网、不上传。

## 使用说明

1. 打开「测试」页，启用面板总开关。
2. 重启小红书（首次启用需重启才会安装 hook）。
3. 逐项打开实验开关；改单个开关后回到小红书约 3 秒生效。
4. 出问题关闭对应开关即可。

## 注意

- 强开的是灰度实验组，不是隐藏福利。部分实验依赖服务端配套数据，可能出现页面空白、字段缺失或崩溃，请一次只开一项、逐项验证。
- 广告、埋点、直播、服务端调参类实验不提供开关。
- 部分 key 只在特定笔记类型/路径下才会被读取；未读取时 UI 显示「尚未读取」。

## 兼容性

- Android 10+ / LSPosed（libxposed API 102）
