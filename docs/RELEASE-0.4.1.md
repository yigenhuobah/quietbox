# 静盒 0.4.1

修复 0.4.0 的一个 AB key 错误。

## 修复

- 「字幕新样式」：实际读取的 key 是 `caption_new_style_v3`，0.4.0 误写成
  `andr_caption_new_style_v3`，导致该开关无效。本版已修正。

## 说明

- 其余功能与 0.4.0 相同。
- 已安装 0.4.0 的用户直接覆盖安装即可；安装后强停重启小红书。
