# 静盒 0.6.0

## 新增

8 项功能，全部独立开关、默认关闭：

- **评分引导弹窗屏蔽**（P1-16）：不弹应用内「满意吗 / 去评分」，
  也不弹 Google Play 系统评分。两个入口都拦。
- **通知引导弹窗屏蔽**（P1-17）：不弹「开启通知」引导。只拦展示，
  你在系统里手动开通知不受影响。
- **满意度调研条屏蔽**（P1-18）：详情页底部不再弹出「对当前的内容满意吗？」。
- **通讯录同步关闭**（P1-19）：不上传通讯录，因此也不会有通讯录推荐好友。
- **评论区带货插入屏蔽**（P1-20）：评论区顶部不再插入商品卡/带货弹层。
  副作用：评论里「提及商品」的插入也会一起失效。
- **直播卡 / 带货卡 / 投票卡过滤**（P1-21/22/23）：信息流里不显示这三类卡片。
  复用信息流广告过滤已验证的列表链路，只移除卡片、不动分页游标。

**版本不兼容警示**：小红书升级后挂载点可能大面积失效，而界面看不出来。
现在挂载统计会在小红书启动时上报，失效 ≥5 个时静盒顶部显示红色提示。
计数健康时不显示，平时界面仍是零诊断内容。

## 修复

- **「首页视频预加载」强开不生效**（v0.5.0 已知问题）：该读点是整数型，
  之前误喂 `"true"`，解析失败被吞掉导致开关永远是空转。已改为 `"1"`。
- **「个人页布局预加载」只点亮一半**：该实验有两个读取点，阈值分别是 >0 和 >1，
  强开值从 `"1"` 改为 `"2"` 才能同时生效。
- **状态卡文案**：未激活时提示「请在 LSPosed 中启用本模块并勾选小红书」，
  此前错误地显示为作用域未勾选。

## 加固

- 每条精选实验现在带声明式的类型标注（BOOL / INT），由 9.50.0 反汇编三重证据
  （TypeToken 泛型注解 + 默认值字面量 + 返回值 check-cast）逐条判定，
  不再靠 key 名猜类型。
- 强制值按声明类型规整：类型不匹配时自动改写；解析失败一律回落到原值并打
  告警日志，不再静默失效。读取值为 null（key 尚未下发）时也能正确强开。
- 「其他」列表里手填的未收录 key 按值的字面形状推断类型。

## 说明

- 新增功能全部默认关闭，请逐项开启验证。直播/带货/投票卡过滤的卡片判定
  优先用 `NoteItemBean.modelType`，字段非空作兜底；若某个版本卡片类型
  映射变了，可能漏过滤，届时反馈即可。
- 通讯录同步关闭会让小红书不再推送「可能认识的人」；若你需要这个功能，
  不要开 P1-19。
- 版本不兼容警示的阈值是 5 个失效挂载点。单个功能失效不会触发提示，
  请以 logcat（tag `QuietBox`）为准。
