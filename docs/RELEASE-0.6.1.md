# 静盒 0.6.1

## 修复

- **复制链接净化**：改用原始编码 query 处理，修复含 `%XX`（如 `xsec_token`）的
  链接静默不净化；参数全部删除时一并去掉 `?`。
- **通讯录同步**：补挂 3 参 `requestContactsSync` 重载，避免部分同步路径漏拦。
- **内容评价**：补挂公开入口 `showContentRatingSnackBarIfNeeded`，防止私有方法
  被内联后失效。
- **开屏**：不再跳过 `startAnim`，避免开屏 fragment 卡住。
- **广告外跳**：放行 `xhsdiscover://` 等站内 scheme，避免误伤站内深链。
- **信息流卡片**：`modelType` 大小写归一；已知类型不匹配时不再用字段兜底，
  避免误删正常笔记。
- **挂载统计**：静默定位失败也会计 miss；统计改为按「功能」去重，横幅仅在
  ≥2 个功能失效时显示；推送改到后台线程且失败可重试。
- **AB 面板**：修复 `refresh()` 只遍历顶层导致状态/摘要不刷新；总开关改值即时
  生效；provider 拉取加 2 秒超时；观测值变化会重发。

## 加固

- 挂载自检按功能去重：≥2 个功能有挂载点失效才显示横幅。
- AB 数据通道增加调用方校验，只接受本应用与小红书。
- 复制链接日志不再输出剪贴板正文。

## 说明

- 适用于小红书 9.50.0（9500803）。
- 修改功能开关后需重启小红书生效；AB 面板单项实验约 3 秒生效。
- 升级小红书后若出现「N/M 个功能有挂载点失效」横幅，说明版本不兼容，
  请回退或等待适配。
